# 目的
1. 本文中の引用文献とcites.bibに記載されている文献に齟齬がないかを確認する
2. 実在する文献を参照しているかを/gemini-search を使って確認しする.
3. 見つかった問題について,解消するためにアフィるを更新するまたは問題の報告を行う.

# プロンプト
1.neuro-shun_paper.tex 内の構成に従って、src 配下のファイルを読み進めてください.

2. 各ファイル内の参考文献を引用している箇所 (正しく引用できていない場合も含む)をリストアップする

3. リストアップした引用文献とbib/cites.bib 内の文献リストを比較する

4. 本文で引用されている文献がbib/cites.bib に文献がない場合 ->文献を /gemini-search で検索し、該当する文献のcite情報を特定する. 文献が存在しない場合はその旨を報告する. 文献が存在した場合は取得したcite情報を bib/cites.bib内に記載する

5. bib/cites.bibで記載されている文献が 本文中で引用されていない場合 -> 当該文献が引用されていないことを報告する. 文章中で引用されそうな適当な箇所の提案を行う. ただしファイルの編集は行わないこと.

6. 最後に文章中での引用文献の初回登場タイミングと cite 内での記載番号に整合性があるかを確認し、順番通りになるように必要に応じて修正する
